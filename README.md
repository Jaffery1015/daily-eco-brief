# 📰 每日经济早报 · 手机版

一个**深色主题、手机友好**的每日经济早报 App（PWA 网页应用）。
每次电脑开机/登录后，由 Windows 计划任务自动搜索最新经济新闻并按模板生成《每日经济早报》（不固定 8:30 推送），
写入 `data/latest.json`；手机打开本应用即可阅读，还支持离线缓存与历史回看。

> ⚠️ 本应用仅供学习参考，不构成投资建议。

---

## 一、这是什么

| 组成 | 说明 |
|---|---|
| `index.html` / `css` / `js` | App 本体（深色主题、手机自适应） |
| `manifest.webmanifest` + `icons` + `sw.js` | PWA 支持：可“添加到主屏幕”像原生 App 一样使用，离线可读 |
| `server.js` + `启动手机版.cmd` | 电脑端一键启动局域网服务器，手机通过 Wi-Fi 访问 |
| `data/` | 报告数据：`latest.json`（最新一期）、`reports/`（每日存档）、`history.json`（历史索引）、`schema.json`（数据格式说明） |
| `automation/每日经济早报-自动化提示词.md` | 供 Codex 定时任务使用的完整提示词 |

报告内容共六大部分：
1. 今日焦点速览（30 秒版）
2. 中国：政策与数据
3. 全球市场与央行
4. 大类资产表现（涨跌按 A 股习惯：红涨绿跌）
5. 今日 / 本周重要日程
6. 经济学学习视角（思考题 + 参考答案，点击即可展开）

## 二、第一次使用（电脑端）

1. 双击项目文件夹里的 **`启动手机版.cmd`**（会启动服务器并打印手机访问地址）。
   - 如果没有 Node.js，脚本会自动尝试 Python；再不行会使用 Codex 自带运行时。
   - 若弹出 Windows 防火墙提示，请选择 **“允许访问”**（专用网络）。
2. 看到类似输出即为成功：

```
每日经济早报 · 手机版服务器已启动
本机访问:  http://localhost:8000
手机访问:  http://192.168.x.x:8000
```

> 服务器需要一直开着，手机才能访问。想停止就关掉这个黑色窗口。

## 三、如何安装到手机（重点）

手机和电脑连**同一个 Wi-Fi**，然后用手机浏览器打开电脑上显示的地址，例如 `http://192.168.x.x:8000`。

### 🤖 安卓手机（Chrome / Edge 浏览器）
1. 用 Chrome 打开上面的地址，等页面加载完成。
2. 点右上角「⋮」菜单 → **「添加到主屏幕」**（或「安装应用 / Install app」）。
3. 确认名称“每日经济早报”，点「添加」。桌面会出现带图标的快捷方式。
4. 以后点击桌面图标，就会像原生 App 一样全屏打开（没有地址栏）。

### 🍎 iPhone / iPad（Safari 浏览器）
1. 用 Safari 打开上面的地址，等页面加载完成。
2. 点底部 **「分享」按钮（方框+箭头）** → 向下滑动 → **「添加到主屏幕」**。
3. 点「添加」。桌面会出现图标，点击即可像 App 一样全屏使用。

### ✅ 安装后的小知识
- **离线可读**：第一次打开后，最新一期会自动缓存到手机，断网也能看（下次联网刷新会更新）。
- **每日更新**：电脑每次开机/登录后会自动生成当天报告并推送到 GitHub，在 App 里点右上角 **🔄 刷新** 即可看到新一期。
- **历史回看**：点右上角 **📚** 可以查看往期早报。
- 服务器未启动时打不开：需先启动电脑端的 `启动手机版.cmd`（或按下文“进阶”部署到公网）。

2. 名称：`每日经济早报`。
3. 提示词：把 `automation/每日经济早报-自动化提示词.md` 中「提示词（从这里开始复制）」整段粘贴进去。
4. 计划：**每周一至周五 08:30**（如可编辑 RRULE：`FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=8;BYMINUTE=30`）。
5. 项目/工作区：选择本文件夹 `C:\Users\jzz20\Desktop\经济早报手机app`；
   执行方式选 **「本地项目目录」**（不要用隔离工作树，否则文件不会写进来）。
6. 保存即可。之后每个工作日 8:30 会自动：搜索新闻 → 按模板生成 → 写入 `data/latest.json` 等文件。

**前提**：电脑开机、Codex 桌面端保持运行。手机端刷新即可看到新一期。

> 建议先手动在 Codex 里跑一次提示词，确认生成的文件没问题，再启用定时任务。

## 四·补充、Windows 任务计划程序方案（已配置好）

本机当前使用 **Windows 任务计划程序** 自动生成早报，不依赖 Codex App 界面、也不依赖固定 8:30：
只要电脑开机并登录，任务就会运行（生成失败还会每 20 分钟自动重试、最长 2 小时）。

### 已配置内容
- 计划任务名称：**每日经济早报**（触发器：用户**登录时**，延迟 1 分钟后运行，并每 20 分钟自动重试、最长 2 小时——开机登录后一定执行）
- 执行脚本：`run-每日早报.ps1`（读取 `automation/exec-提示词.txt` → 运行 `codex exec` → 写入 data 目录）
  - 自带 **40 分钟超时**：codex exec 卡住（网络重连等）会自动终止，不再无限挂起
  - 自带**自愈恢复**：若 codex 因只读沙箱等原因未能落盘，脚本会从 `logs\最近一次-汇报.txt` 自动恢复 4 个文件（`automation\extract-report-from-log.ps1`）
  - 只有确认当日报告真实生成后才提交推送，避免“假成功”
  - 开机/登录后 **cc-switch 未就绪会自动等待最长 120 秒**，避免刚开机就失败
  - **单实例保护**：重复触发不会并发生成
  - 推送到 GitHub 直连失败时**自动改走本地代理**（127.0.0.1:7897）重试
- 运行日志：`logs\运行日志.log`、`logs\codex-运行输出.log`、`logs\最近一次-汇报.txt`
- 已添加 **cc-switch 开机自启**（本地模型代理必须在线，任务才能连上 DeepSeek）

### 常用命令（在 PowerShell 或 CMD 中）
- 立即运行一次：`schtasks /Run /TN "每日经济早报"`
- 查看状态：`schtasks /Query /TN "每日经济早报" /V`

### 修改 / 暂停 / 删除
- 改时间：开始菜单搜「任务计划程序」→ 任务计划程序库 → 右键「每日经济早报」→ 属性 → 触发器
- 暂停：右键 → 禁用；删除：右键 → 删除
- 改提示词：编辑 `automation/exec-提示词.txt`，下次运行自动生效
- 移除开机自启：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 删除 `cc-switch`（或在 cc-switch 设置里关闭“开机自启”）

### 注意事项
- 必须保持 **cc-switch** 后台运行（已设开机自启；如未生效请手动打开 cc-switch 并开启本地代理）。
- 生成会消耗 DeepSeek 额度，正常每次约 5 分钟、数万 token。

## 七、常见问题

- **手机打不开页面？** 确认手机和电脑同一 Wi-Fi；确认服务器窗口还开着；确认防火墙已允许（或临时关闭防火墙测试）。
- **IP 地址变了吗？** 重启路由器/换网络后 IP 会变，重新运行 `启动手机版.cmd` 查看新地址。
- **端口被占用？** 关掉占用 8000 端口的程序，或设置环境变量 `PORT=8080` 后重新启动。
- **某天没有新早报？** 说明当天电脑没有开机/登录（周末或节假日若开机登录也会生成当天一版）；App 会保留最新一期。
- **数据不准/缺失？** 以 `dataCutoff`（数据截止时间）为准，自动化每天重新检索，个别数据假期缺失时会显示“—”。
